# ShowCase Releases

Public release artifacts and auto-update feed for ShowCase.

- **Downloads**: see [Releases](https://github.com/Dobbs3313/ShowCase-releases/releases)
- **Auto-update feed**: [`appcast.xml`](appcast.xml) — consumed by Sparkle (macOS) and WinSparkle (Windows) inside the app

Artifacts are built and published automatically by CI from the private source repo when a `v*` tag is pushed.
